# 공문 바로쓰기

공문 내용을 입력하면 **공문서 규격에 맞게 정리**하고 **고칠 곳을 알려 주는** 웹앱입니다.
서버나 설치 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다. 입력한 내용은 이 브라우저에만 저장됩니다.

## 하는 일

**자동 정리 (완성본)**
- 항목 기호를 `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 순서로 다시 매깁니다.
- 하위 항목은 2타씩 들여 쓰고, 둘째 줄부터는 내용 첫 글자에 맞춥니다(내어쓰기).
- 본문이나 붙임 끝에 2타 띄우고 `끝.`을 붙입니다.
- `붙임  1. ○○ 1부.` 형식으로 붙임을 정리합니다.
- 글꼴, 글자 크기, 줄 간격, 자간을 A4 미리보기에 반영합니다(기본값: 휴먼명조 15pt, 160%).
- 서식 포함 복사(한글·워드에 붙여 넣기), 텍스트 복사, 인쇄·PDF 저장을 지원합니다.

**고칠 곳 알려 주기**
| 분류 | 예 |
|---|---|
| 표기 | `2026년 9월 28일` → `2026. 9. 28.`, `오후 2시` → `14:00`, 틀린 요일, 금액 쉼표 |
| 띄어쓰기 | `할수있다` → `할 수 있다`, `에따라` → `에 따라`, `A및B`, `제 1조` |
| 문장부호 | `관련 :` → `관련:`, 쉼표 뒤 띄어쓰기, 괄호 안 공백 |
| 항목 | 기호 순서·번호 차례가 틀린 곳 |
| 붙임 | 수량(`1부.`) 누락 |
| 쉬운말 | `금일` → `오늘`, `유첨` → `붙임`, `만전을 기하여` → `철저히 하여` 등 |
| 구조·문장 | 제목 끝 온점, 수신자 누락, 지나치게 긴 문장 |

각 항목의 **고치기** 버튼으로 하나씩, 또는 **한 번에 고치기**로 모두 반영합니다.
요일 오류처럼 사람이 판단해야 하는 항목은 한 번에 고치기에서 빠집니다.

## 기준과 한계
- 「행정업무운영 편람」의 기안문 작성 방법, 「한글 맞춤법」, 국립국어원 공공언어 다듬은 말을 기준으로 삼았습니다.
- 글꼴·크기는 기관마다 정한 서식이 다를 수 있으니 설정에서 맞춰 쓰세요.
- 규칙 기반 검사라 모든 맞춤법 오류를 잡지는 못합니다. 최종 확인은 직접 해 주세요.

## 파일

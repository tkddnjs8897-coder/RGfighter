# 스즈키 GSX-S1000GX 시세알리미

바튜매(네이버카페), 당근마켓, 번개장터, 라이트바겐에서 직접 확인한 매물 가격을
등록해두면, 튜닝여부·키로수·년식 조건에 맞는 시세를 추정해주는 로컬 웹앱입니다.

외부 패키지 없이 Node.js 표준 라이브러리만 사용합니다.

## 실행 방법

```bash
cd price-alert
node server.js
```

브라우저에서 http://localhost:3000 접속.

## 왜 자동 수집을 안 하나요?

- 바튜매(네이버카페)는 로그인해야 검색 결과가 노출되고, 라이트바겐/당근마켓/번개장터는
  공식 API가 없어 자동 스크래핑 시 이용약관 위반·차단 위험이 있습니다.
- 그래서 이 앱은 "빠른 검색" 버튼으로 각 플랫폼 검색 페이지를 새 탭으로 열어주고,
  사용자가 직접 확인한 가격을 수동으로 입력하는 방식을 사용합니다.

## 기능

1. **빠른 검색**: 당근마켓/번개장터/네이버 통합검색을 검색어와 함께 새 탭으로 엽니다.
   (바튜매·라이트바겐은 로그인/전용 도메인이 필요해 자동 링크 생성 대상에서 제외했습니다.
   즐겨찾기로 직접 방문 후 가격을 확인해주세요.)
2. **비교 매물 등록**: 플랫폼, 가격, 년식, 키로수, 튜닝여부/내용, 출처링크, 메모를 저장합니다.
   (`data/listings.json`에 저장되어 서버를 재시작해도 유지됩니다.)
3. **시세 추정**: 등록된 매물들을 대상으로, 입력한 년식·키로수·튜닝여부와 가까운 매물일수록
   더 큰 가중치를 주는 가중평균으로 추정 시세를 계산합니다.
4. **이 가격 괜찮아?**: 후보 매물 가격을 함께 입력하면 추정 시세 대비 ±10% 기준으로
   저렴/적정/비쌈을 판정합니다.

## 데이터 백업

`data/listings.json` 파일 하나에 모든 매물이 저장됩니다. 필요하면 그대로 복사해서
백업하거나 다른 기기로 옮길 수 있습니다.
